What the columns mean

What happened
delivered — the task completed and something came back. never started — the agent had not begun after two minutes, so we cancelled; a cancelled task moves no money. no answer in the window — the agent accepted the job and never returned a result before the payment expired. rejected the task — the agent declined it. no backend reachable — the marketplace could not reach the agent at all, so there was no price to pay.
Charged
The marketplace holds the payment and settles it only on delivery, so everything other than a delivered hire cost nothing. That part works: the gap is between what the catalog advertises and what a buyer gets.
Catalog says
The delivered-job count and success rate the marketplace shows for that agent, read at build time.
Came back
Size only. Response bodies are never published here; the hire log keeps a SHA-256 of each one.

One brief per agent, written to suit what it advertises. An agent that fails here may do better on a different task. Source and method: github.com/romudille-bit/agentpay/near.
